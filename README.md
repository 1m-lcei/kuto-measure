# Kuto Measure

## ⚠️ 動作確認用 α版

> [!WARNING]
> **現在は動作確認用のα版です。**
> **測定結果は目安として扱ってください。画像と編集全体を再編集できる形で保存する機能は未実装です。基準円とカメラ設定は1件保存できます。**

ブルーアーカイブ戦術対抗戦シーズン11のスクリーンショット画像を下敷きにして、距離を測るツールです。
ブラウザ内だけで処理し、画像ファイルや編集データは外部へ送信しません。

## 基本的な使い方

1. PNG・JPEG・WebPの静止画像を開くか、画像領域へドロップします
2. オプション：「基準円」で中心と円周を順にクリックし、ハンドルで位置と半径を調整します
3. オプション：基準円のゲーム内半径を入力します。これが距離の基準になります
4. ピンを置きます
5. ピンを2つ選んで測距線を作成します

基準円が未設定なら、最初の測距線を1として相対距離を表示します。

ピンの十字の交点が測定位置です。ピンは1つのグループに所属でき、グループ中心は所属ピンの座標の平均位置になります。
ピンやグループを削除すると、それを直接参照する測距線・補助円も削除されます。「元に戻す」で一緒に復元できます。

## 操作

- ホイールで拡大・縮小、Space＋ドラッグ／中ボタンドラッグ／パンモードで表示位置を移動します
- Ctrl／Cmd＋Zで元に戻し、Ctrl＋YまたはCtrl／Cmd＋Shift＋Zでやり直します。直近100操作まで戻せます
- タッチでは現在、1本指操作と倍率ボタンを使用します
- 選択ツールでは、カーソル下の対象を輪郭で強調します。重なる対象は、配置をずらしたラベルからクリック・タップ・Enter／Spaceで個別に選択できます。ラベルのドラッグでは測定点は動きません
- ピンツールではカーソルと重なる既存の図形・ラベルだけを薄くし、下絵を見ながら連続配置できます
- 「PNGを書き出す」で保存します。対応ブラウザではOSの保存ダイアログで名前と保存先を指定できます。非対応の場合は通常のダウンロードを開始し、保存ダイアログの表示や保存先はブラウザの設定に従います。元解像度で出力し、ラベルの配置改善は含めますが、選択表示・薄表示は含めません

ラベルは測定位置を変えずに移動し、引出線で対象と結びます。密集して収まらない場合は拡大するか、オブジェクト一覧を使用してください。
PNGでは元解像度でラベルを配置し直すため、画面の倍率によって配置が異なる場合があります。

## 高度な設定

メニューの「高度な設定を表示」をONにすると、基準パネルでピッチ角・垂直画角・
ロール角・主点を調整できます。初期状態はOFFで、ページを開き直すとOFFに戻ります。
画像を開いてから数値を入力し、「投影設定を適用」で反映します。Undo／Redoに対応します。
OFFにしても適用済みの値は維持されます。別の画像を開くと、保存した基準があればそのカメラ設定、なければ初期値を使います。
ピンの画像上の位置は維持しますが、基準円の形と測距結果は変わります。
詳しくは[投影パラメータの説明](docs/measurement.md#投影パラメータの手動調整)を参照してください。

## 測定できる画像と注意点

- PNG・JPEG・WebPの静止画像に対応します。最大256 MiB・50メガピクセルで、アニメーションは使用できません
- 平らな地面上の距離を対象にしています。高低差は認識できません
- ゲーム映像全体を残した画像を使ってください。原則として、戦術対抗戦シーズン11にのみ対応しています
- 画像の上下・左右にある帯は自動判定します。除外した領域との境界は細い赤線で表示します。この赤線はPNG出力には含まれません
  - 他のアプリなどの表示があると、自動判定できない場合があります

## 保存とプライバシー

- 基準パネルの「保存・リセットの操作」から、確定済みの基準円とカメラ設定を1件保存・上書き・削除できます。ゲーム内半径まで設定してから保存してください
- 保存した基準は画像を開くたびに自動適用し、「保存した基準を使用中」と表示します。同じ撮影条件で使い、適用後に円の位置・大きさを確認してください。撮影条件の一致を自動判定する機能ではありません
- 円の調整やUndo／Redoで保存内容は自動更新しません。「現在の基準で上書き」が必要です
- 「この画像の基準をリセット」は円とカメラ設定を初期化し、ピンの画像上の位置と保存した基準は保持します。Undo／Redoに対応します。「保存した基準を削除」は保存レコードだけを削除し、現在の画像には影響しません
- 保存先は同じブラウザ・配信元のlocalStorageです。サイトデータの削除等で失われます。不正・適用不能な保存内容は使わず、初期設定で画像を開きます
- **画像・ピン・測距線などの編集全体は保存されず、ページを閉じるか別画像へ切り替えると失われます**。基準を自動適用しただけでは破棄確認を出さず、実際の変更があるときに確認します
- 画像ファイルや編集データの外部送信は行いません
