# Kuto Measure

ブルーアーカイブの戦術対抗戦シーズン11のスクリーンショットを下敷きに、距離を測るブラウザツールです。
画像や編集データはブラウザ内のみで処理し、外部へ送信しません。

> 現在は動作確認用のα版です。測定結果は目安として扱ってください。

## 基本的な使い方

1. PNG・JPEG・WebPの静止画像を開くか、画像領域へドロップします。
2. ゲーム領域を確認し、範囲が合わない場合は、警告表示横の「ゲーム領域を設定」ボタンから、あるいは、パネルの「画像・基準」→「ゲーム領域」と進んで調整します。
3. 測りたい位置にピンを置きます。
4. 測距線ツールを選択し、ピンを2つクリックします。

最初の測距線を1とする相対距離を表示します。
ゲーム内の距離で測るには、「基準円」で中心と円周を指定し、位置・大きさを合わせてゲーム内半径を入力してください。

## 主な操作と保存

- **移動・拡大縮小**：ドラッグで表示位置を移動し、ホイールで拡大・縮小します。タッチではピンチして拡大縮小できます。
- **編集**：「選択」で対象を選び、選択済みのピンやハンドルをドラッグして調整します。Escapeで操作を取り消します。
- **元に戻す・やり直す**：Ctrl／Cmd＋Zで元に戻し、Ctrl／Cmd＋Shift＋Zでやり直します。
- **画像として保存**：「PNGを書き出す」で画像として保存します。
- **編集を保存・再開**：メニューの「編集をJSONで保存」で保存します。再開するときは元の画像を開き、「編集JSONを読み込む」を選びます。

JSONに画像本体は含まれません。元画像は別途保管し、ページを閉じる前に編集内容を保存してください。

## 注意点

- ゲーム映像全体の画像を使ってください。
- 自動判定されたゲーム領域が正しいか確認してください。
- 高低差は考慮していません。
