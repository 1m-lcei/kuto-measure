# Kuto Measure

## ⚠️ 動作確認用 α版

> [!WARNING]
> **現在は動作確認用のα版です。**
> **測定結果は目安として扱ってください。編集内容はJSONで保存できます。画像本体は別途保管してください。**

ブルーアーカイブ戦術対抗戦シーズン11のスクリーンショット画像を下敷きにして、距離を測るツールです。
ブラウザ内だけで処理し、画像ファイルや編集データは外部へ送信しません。

## 基本的な使い方

1. PNG・JPEG・WebPの静止画像を開くか、画像領域へドロップします
2. ゲーム領域を確認し、正しければ画像サイズ下の「OK」を押します。帯が合わない場合は基準パネル先頭で上下左右の除外幅を指定し、帯がない場合は「画面全体を適用」を選びます
3. オプション：「基準円」で中心と円周を順にクリックし、ハンドルで位置と半径を調整します
4. オプション：基準円のゲーム内半径を入力します。これが距離の基準になります
5. ピンを置きます
6. ピンを2つ選んで測距線を作成します

オブジェクトを選択し、「↑ 上へ」「↓ 下へ」で同じ種類の中の順序を変更できます。並び順は編集JSONに保存され、元に戻す・やり直すにも対応します。

基準円の半径が未設定なら、先頭の測距線を1として相対距離を表示します。並び替え・削除で先頭が変わると、新しい先頭の線が基準になります。

ピンの十字の交点が測定位置です。ピンは1つのグループに所属でき、グループ中心は所属ピンの座標の平均位置になります。
ピンやグループを削除すると、それを直接参照する測距線・補助円も削除されます。「元に戻す」で一緒に復元できます。

## 操作

- どのツールでもドラッグで表示位置を移動します。「選択」ではクリック・タップで対象を選び、選択済みのピンやハンドルをドラッグすると位置や半径を調整できます
- 配置や描画は各ツールを選び、クリック・タップで指定します。Escapeで操作を取り消して「選択」に戻ります
- ホイールで拡大・縮小。選択済みの対象の上でもSpace＋ドラッグ／中ボタンドラッグなら表示位置を移動できます
- 「選択」で対象が未選択のときは矢印キーでも表示位置を移動できます。Shiftを押すと移動量が大きくなります
- Ctrl／Cmd＋Zで元に戻し、Ctrl＋YまたはCtrl／Cmd＋Shift＋Zでやり直します。直近100操作まで戻せます
- タッチでは2本指で表示位置を移動、ピンチで指の間隔に比例して拡大・縮小できます。片指を離しても残った指で移動を続けられます。2本指に切り替えると未確定のドラッグ編集を取り消し、全ての指を離すまで選択・配置・編集を再開しません。倍率ボタンも使用できます
- 「選択」では、カーソル下の対象を輪郭で強調します。重なる対象は、配置をずらしたラベルからクリック・タップ・Enter／Spaceで個別に選択できます。ラベルのドラッグでは表示位置を移動し、測定点は動きません
- ピンツールではカーソルと重なる既存の図形・ラベルだけを薄くし、下絵を見ながら連続配置できます
- 「PNGを書き出す」で保存します。対応ブラウザではOSの保存ダイアログで名前と保存先を指定できます。非対応の場合は通常のダウンロードを開始し、保存ダイアログの表示や保存先はブラウザの設定に従います。元解像度で出力し、ラベルの配置改善は含めますが、選択表示・薄表示は含めません

ラベルは測定位置を変えずに移動し、引出線で対象と結びます。密集して収まらない場合は拡大するか、オブジェクト一覧を使用してください。
PNGでは元解像度でラベルを配置し直すため、画面の倍率によって配置が異なる場合があります。

## 高度な設定

メニューの「高度な設定を表示」をONにすると、基準パネルでピッチ角・垂直画角・
ロール角・主点を調整できます。初期状態はOFFで、ページを開き直すとOFFに戻ります。
画像を開いてから数値を入力し、「投影設定を適用」で反映します。Undo／Redoに対応します。
OFFにしても適用済みの値は維持されます。別の画像を開くと、保存した基準があればそのカメラ設定、なければ初期値を使います。
ピンの画像上の位置は維持しますが、基準円の形と測距結果は変わります。
詳しくは[投影パラメータの説明](docs/measurement.md#投影パラメータの手動調整)を参照してください。

## ゲーム領域の設定

基準パネルの先頭にある「ゲーム領域」は標準で折りたたまれています。開くと、画像の上・下・左・右から除外する幅を整数pxで指定できます。
入力中の破線はプレビューです。「適用」で測定に反映し、「取消」またはEscapeで入力を戻します。
「自動検出を適用」は読み込み時の結果を、「画面全体を適用」は画像全体を確認済みとして適用します。
画像を開くと自動検出の成否にかかわらず、画像サイズの下に赤文字で「ゲーム領域が正しく判定されていない場合、設定の必要があります」と表示します。左の「OK」で現在の領域を変更せず確認済みにできます。横の「ゲーム領域を設定」で設定を開き、入力欄に移動できます。
確認状態は画像ごとに初期化され、手動設定・各「適用」操作でも確認済みになります。「OK」だけの操作では画像切替時に編集破棄の確認を出しません。
ゲーム領域が画像全体と一致する場合は、サイズの代わりに「画像全体」とアスペクト比を表示します。距離スケールの設定とは別に確認してください。
自動検出でも境界が正しいか確認してください。手動設定はゲーム映像全体を囲むためのもので、切り抜き済み映像の復元はできません。

変更時もピンと自由な補助円中心の画像上の位置を保ちます。基準円は中心と円周上の一点を保ち、形と測距値は変わるため合わせ直してください。
領域外の注釈は削除されず、画面・PNGでは隠れます。領域と編集内容はUndo／Redoで一緒に戻せます。
設定は画像ごとで、保存した基準には含めません。基準リセットは領域を保持します。

## 測定できる画像と注意点

- PNG・JPEG・WebPの静止画像に対応します。最大256 MiB・50メガピクセルで、アニメーションは使用できません
- 平らな地面上の距離を対象にしています。高低差は認識できません
- ゲーム映像全体を残した画像を使ってください。原則として、戦術対抗戦シーズン11にのみ対応しています
- 画像の上下・左右にある帯は自動判定します。除外した領域との境界は細い赤線で表示します。この赤線はPNG出力には含まれません
  - 小さなカーソルが青帯に重なっても判定できるようにしています。大きな表示や非対称の帯など、自動判定が合わない場合は手動設定してください

## 保存とプライバシー

- 基準パネルの「保存・リセットの操作」から、確定済みの基準円とカメラ設定を1件保存・上書き・削除できます。ゲーム内半径まで設定してから保存してください
- 保存した基準は画像を開くたびに自動適用し、「保存した基準を使用中」と表示します。同じ撮影条件で使い、適用後に円の位置・大きさを確認してください。撮影条件の一致を自動判定する機能ではありません
- 円の調整やUndo／Redoで保存内容は自動更新しません。「現在の基準で上書き」が必要です
- 「この画像の基準をリセット」は円とカメラ設定を初期化し、ピンの画像上の位置と保存した基準は保持します。Undo／Redoに対応します。「保存した基準を削除」は保存レコードだけを削除し、現在の画像には影響しません
- 保存先は同じブラウザ・配信元のlocalStorageです。サイトデータの削除等で失われます。不正・適用不能な保存内容は使わず、初期設定で画像を開きます
- メニューの「編集をJSONで保存」でピン・グループ・測距線・補助円・基準円・カメラ設定・ゲーム領域・画像サイズを保存できます。画像本体・操作履歴・表示倍率は含みません
- 画像を開き、メニューの「編集JSONを読み込む」で復元します。画像サイズが違う場合も確認後に読み込めます。ゲーム領域を画像サイズの比率に合わせ、地面座標を保持します。縦横比が違う場合は特に位置を確認してください。読み込み自体はUndo／Redoで戻せます。不正なJSONは現在の編集を変えずにエラーを表示します
- 未保存の編集はページを閉じるか別画像へ切り替えると失われます。基準を自動適用しただけでは破棄確認を出さず、実際の変更があるときに確認します
- 画像ファイルや編集データの外部送信は行いません
