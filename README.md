# Kuto Measure

## ⚠️ 動作確認用 α版

> [!WARNING]
> **現在は動作確認用のα版です。測定精度や動作は検証中です。**
> **測定結果は目安として扱ってください。解析内容を再編集できる形で保存する機能はありません。**

ゲームのスクリーンショットから、地面上の距離を測るブラウザツールです。
画像と解析内容はブラウザ内だけで処理し、外部へ送信しません。

## 使い方

1. PNG・JPEG・WebPの静止画像を開くか、画像領域へドロップします。
2. 「基準円」で中心と円周を順に選び、ハンドルで位置と半径を調整します。
3. 基準円のゲーム内半径を入力します。これが距離の基準になります。
4. ピンを置き、必要ならパネルでグループを作成して所属を設定します。
5. ピン・グループ中心を2つ選んで測距線を作成します。補助円は任意の地面位置または対象に取り付けられます。
6. 「PNGを書き出す」で、元画像の解像度に注釈を重ねた画像を保存します。

基準円の設定は独立したパネルにあり、「設定時にパネルを閉じる」は初期ONです。
基準円の半径が未設定なら、最初の測距線を1として相対距離を表示します。
その線を動かすと比率も変わり、削除すると次の線が基準になります。

ピンの十字の交点が測定位置です。ピンは1つのグループに所属でき、グループ中心は所属ピンの地面上の平均位置になります。
空のグループや距離の基準が未設定の円は一覧に残りますが、画像上には表示されません。
ピンやグループを削除すると、それを直接参照する測距線・補助円も削除されます。「元に戻す」で一緒に復元できます。

## 操作

- ホイールで拡大・縮小、Space＋ドラッグ／中ボタン／パンモードで表示位置を移動します。
- Escapeで取消、Deleteで削除します。
- Ctrl／Cmd＋Zで元に戻し、Ctrl＋YまたはCtrl／Cmd＋Shift＋Zでやり直します。直近100操作まで戻せます。拡大・縮小と表示位置の移動は含みません。
- タッチでは1本指操作と倍率ボタンを使用します。
- キーボードでは画像領域の矢印キーとEnterで配置できます。
- メニューからライト・ダーク・システムのテーマを選べます。

## 測定できる画像と注意点

- PNG・JPEG・WebPの静止画像に対応します。最大256 MiB・50メガピクセルで、アニメーションは使用できません。
- 平らな地面上の距離を対象にしています。坂・高低差・空中の点は正しく測定できません。
- ゲーム映像全体を残した画像を使ってください。ゲーム映像そのものの切り抜きや縦横比の変更、ゲーム側のカメラ変更には対応していません。
- 画像の上下・左右にある帯は自動判定します。除外した領域との境界は細い赤線で表示します。この赤線はPNG出力には含まれません。
- 大きな動画プレーヤー枠などは自動判定できない場合があります。その場合は余白だけを除き、元のゲーム映像全体を残して読み込み直してください。領域を手動指定する機能はありません。
- 基準円の半径を設定しても、画像の位置や方向による測定のずれが直るわけではありません。すべての端末・ゲームモードでの精度は確認できていません。

## 保存とプライバシー

**解析内容はタブを閉じるか、別の画像へ切り替えると失われます。必要な結果はPNGで書き出してください。**
PNGからピンや円を再編集することはできません。

画像・解析内容の外部送信やアクセス解析は行いません。テーマ設定だけを端末に保存します。
