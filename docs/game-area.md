# ゲーム領域

ゲーム領域は元のゲーム映像の範囲です。画像・検出用の画素はブラウザ内で処理します。
表示・当たり判定・投影・PNGの注釈に同じ適用済み領域を使います。

## 状態と確認

読み込み時の自動検出結果は画像リソースに、適用済み領域と状態は編集ドキュメントに保持します。画像未選択時だけ領域は `null` です。

| 由来 | 意味 |
| --- | --- |
| `fallback` | 画像全体で仮計算 |
| `auto` | 帯を自動検出 |
| `manual` | 手動適用。除外幅がすべて0の場合も含む |
| `full` | 画像全体を明示選択 |

確認状態は別の `confirmed` フラグです。新しい画像は検出の成否にかかわらず未確認から始めます。
未確認時は画像サイズの下に同じ文字サイズの赤文字で「ゲーム領域が正しく判定されていない場合、設定の必要があります」と表示します。編集・PNG出力は継続できます。
「問題なし」は領域を変えず確認済みにします。「ゲーム領域を設定」は基準パネルと領域設定を開き、最初の入力欄へフォーカスします。
確認状態はUndo／Redoの対象ですが、確認だけでは画像切替時の編集破棄確認を出しません。領域が画像全体と一致する場合は「画像全体」とアスペクト比を表示します。

## 手動設定

基準パネル先頭の「ゲーム領域」は初期状態では折りたたまれています。

- 上下左右の除外幅を元画像の整数pxで入力します。全項目必須、0以上、残る幅・高さは1px以上です。空欄・小数・非有限値・画像外の範囲はフォームとモデルで拒否します。
- 未適用の入力は破線の矩形だけに反映し、測定・出力には使いません。取消・Escape・パネルを閉じる操作・Undo／Redo・画像切替で破棄します。
- 「適用」は手動設定、「自動検出を適用」は読み込み時の結果、「画面全体を適用」は4辺0を、いずれも確認済みとして1操作で反映します。

「バーをドラッグして調整」は初期状態OFFです。ONにすると上下左右のバーをマウス・タッチで動かせます。数値入力と同じプレビューを使い、整数pxに丸め、幅・高さ1px以上を残します。
矢印キーで1px、Shift併用で10px調整できます。ドラッグ中断時は未適用入力を破棄し、2本指に切り替えると表示の移動・拡大縮小に移ります。
手動適用の成功でOFFに戻ります。バーは領域設定を開いている間だけ表示し、PNG・編集JSONには含めません。

## 領域変更と保存

領域変更はカメラ変更と同じ再投影処理を使います。ピンと自由な補助円中心の画像座標、基準円の中心と変更前の地面+X側の円周点を保持し、基準円の地面半径を再計算します。
ゲーム内半径と参照関係は保持し、グループ中心・距離・スケールを再計算します。変換不能な点や不正な基準円があれば変更全体を拒否します。
領域外のデータは保持し、注釈を領域内にクリップする旨をフォームに表示します。

領域・状態・再投影したデータは同じ履歴に含めます。同じ領域で状態だけ変える場合は再投影しません。Undo／Redoで警告・入力値・境界・距離も復元します。
保存基準は領域を含みません。基準の保存時検証とリセットには適用済み領域を使い、リセットは領域設定を保持します。画像切替は再検出して状態を初期化します。
PNGは画像全体を元解像度で保持し、編集用境界・未適用プレビューを含めません。

## 自動検出

`src/image.ts` の `detectRenderArea` は最大256 × 1024pxのサンプルから、次の順で領域を求めます。

1. 外縁の単色または青い模様の帯を探し、向かい合う帯の厚さがほぼ同じ場合に除外します。帯の最小厚さは2pxまたは軸長の1%の大きい方、両端からの除外幅は軸長の22%未満です。
2. 上下の通常判定が失敗した場合は、各行の左右それぞれ外側25%にある青い不透明画素を調べます。RGB各成分の中央値から32を超えて離れる画素を除き、残った画素がサンプル範囲の70%以上で色の分散が小さい場合を候補にします。中央のホームインジケーターや小さなカーソルの影響を抑え、画像高さの4%以内の外枠を越えて対称な帯を探します。
3. 対称な上下帯を検出できない場合は、高さ6%以内の明るい／暗い無彩色に近いタイトルバーと、その直下・画像下側の青い帯を探します。タイトルバーは中央80%の画素の90%以上が同じ明暗範囲に収まることが条件です。上下の厚さが違っても、各青帯が画像高さの22%未満で、内側が青帯の条件を満たさなくなる場合に採用します。下端の枠の探索幅は4%以内です。

対称判定を優先し、片側の帯から反対側を推測しません。小さな断片や青帯同士の色の変わり目は採用しません。判定できない軸は画像の端から端までを使います。
画像全体を使う結果も、帯がないことの保証にはなりません。色付き・大きなタイトルバー、字幕、大きな操作部、タイトルバーの特徴がない非対称な帯、青い場面では失敗・誤判定する場合があります。
自動検出した境界を確認し、必要なら手動で設定してください。

投影の式と測距への影響は[幾何モデル](geometry.md)・[測距の仕組み](measurement.md)、過去の画像比較は[校正の記録](calibration/README.md)を参照してください。
