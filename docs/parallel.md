# 平行線の表示・スナップ・移動

## 平行線の表示

平行関係と移動は地面座標で計算します。地面上で向きの差が0.1°以下の線の組には、各線の中点に共通の `>>` 印を表示します。印は線に沿って向きを合わせますが、線の向きを示す矢印ではありません。端点を解決できない線や、端点が同一点で角度を解決できない線は対象外です。端点の順序が逆の線や同一直線上の線も含め、直接の組ごとに判定します。推移的なグループ化はしません。

線を選択すると、その線と直接平行な線を強調します。スナップ中の線の組も強調します。平行印は常に表示されますが、選択・スナップの強調はPNGに含めません。PNGには平行印を含めます。

## 平行スナップ

選択ツールの操作欄にある平行スナップは初期状態でオンです。設定はブラウザーのlocalStorage `kuto-measure.parallel-snap` に保存し、編集データには含めません。Shiftを押している間だけ一時的にスナップを無効化し、キーを離すと現在位置で再判定します。

スナップは選択ツールで既存のピンをドラッグするときだけ行います。動かすピンに直接つながる線だけが対象です。線の反対側の端点が不変で、参照線も不変である必要があります。通常のピンを動かす場合、同じグループの他の通常ピンは動かないため候補にできます。反対側端点がそのグループの中心の場合は、移動ピンによって中心が変わるため除外します。また、グループ中心を端点に持つ参照線など、グループ中心の変化で動く参照線も除外します。新しい線の作成、線全体の移動、矢印キーによる移動ではスナップしません。

候補は生の角度差が3°以下で、平行にするための最短画像座標補正量に現在のズーム倍率を掛けた値が8 CSS px以下の場合に限ります。条件を満たす候補のうち補正量が最小の線に合わせ、端点を正確に平行な位置へ動かします。線の長さは変わることがあります。同じ補正量なら現在の線の組を優先し、それでも同じなら測定一覧の順に決めます。ドラッグ中に角度差または補正量の条件を外れるとスナップを解除します。

スナップは移動時の補助であり、永続的な平行拘束を作りません。

## 線全体の移動

選択ツールで線を選び、線本体をドラッグすると線全体を平行移動できます。ピンのドラッグは従来どおり単一ピンの移動で、ラベルのクリックは対象の選択だけを行います。矢印キーは従来の移動ステップで線全体を動かします。Shiftと矢印キーでは同じステップを10倍にします。

平行移動では地面座標上の同じ差分を両端へ加えるため、長さと向きを保ちます。端点参照がグループ中心の場合は、そのグループの全メンバーピンを移動します。通常のピンを端点参照する場合は、そのピンだけを移動します。複数端点に共通するピンは一度だけ移動します。共有線・円・グループ中心は更新後の位置から再計算されます。基準線が変われば相対距離も再計算します。

移動後のピンがゲーム領域外に出る操作は拒否し、最後の有効な位置を保ちます。ドラッグは1回のUndo操作です。Escapeまたはキャンセルでドラッグ全体を破棄します。平行関係や印は編集データの派生表示であり、プロジェクトの保存形式に追加データを持ちません。
