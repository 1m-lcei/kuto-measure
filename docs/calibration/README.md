# 校正の記録

## 採用した設定

| 項目 | 値 |
| --- | --- |
| 地面に対する俯角 | 25.2° |
| 画面の傾き（消失線の傾き） | 0° |
| 描画領域の縦画角 | 9.92° |
| 主点 | 描画領域内の (0.5, 0.5) |
| 解像度・縦横比の変換 | 描画領域の高さで焦点距離を換算。幅の変化は横の可視範囲の変化として扱う |

実際の設定は `src/geometry.ts` の `DEFAULT_CALIBRATION` に一か所だけ保持する。

## 元画像との照合

対象は `BlueArchive 2026-09-26 070718_1.png`（3840 × 2160）。青い上下帯の境界は
およそ y=146 / 2014、描画領域は3840 × 1868。縮小サンプリングによる自動判定には
数pxの差が生じる。

1. 床の直交する目地を、画面内の異なる場所から抽出して直線近似した。
2. 横幅1536pxに換算した消失点の概算は (-1696, -1590) と (9941, -1591)。
   主点を (768, 432)、画素を正方形とすると、
   `f² = -(v1-c)・(v2-c)` から焦点距離約4300px、俯角約25.2°、傾きほぼ0°となる。
3. この床からの推定値を丸め、俯角25.2°・傾き0°・縦画角9.92°を採用した。
4. キャラクターやUIに隠れていないゲーム内円弧の3区間、計102点で円の中心・半径を
   最小二乗で求めた。中心は元画像で約 (804.0, 1680.4) となり、キャラクターの足元付近。
   中心は円弧からの推定であり、独立した既知の正解座標ではない。

推定した中心位置を固定し、採用した投影で半径を合わせると、円弧への法線方向の
誤差（二乗平均平方根）は約1.2px、最大誤差は約6.3pxだった。
値は元画像の3840px幅で、発光した線の太さや遮蔽の影響も含む。
これは見えている3区間の結果で、隠れた円周や全画面の測距誤差を保証する値ではない。

[range-2026-09-26.json](range-2026-09-26.json) に床の推定消失点、描画領域、
円の中心・半径、および円弧を4点おきに間引いた26点を記録した。`tests/core.test.ts`
はその円弧と投影円の距離を確認する。画像そのものはリポジトリに同梱しない。

## 端末ごとの操作を不要にする前提

ユーザー指定に基づき、モード・端末間の投影は共通とし、帯と横方向の表示範囲で
画面に収める。カメラ設定と画像ごとの描画領域を分離した。認識できる対の帯は
画像読み込み時に自動で取り除いて計算し、帯のない画像では画像全体を使う。
書き出し画像は元のサイズ・帯を維持する。

この2画像だけから全端末の表示規則を確定したわけではない。特に、帯が映像に
重なっているだけの場合、任意の編集で切り抜いた画像、非対称・別デザインの帯、
モード側のカメラ変更は、この自動判定・共通カメラの前提では識別できない。
帯が曖昧な場合にユーザーへ調整を求める機能は設けず、その軸は画像全体を使う。

対抗戦画像の線路方向の消失点は約 (-1551, -1560) と推定した。
枕木方向は短い辺のため推定に幅がある。
共通設定に大きく反する結果ではないが、対抗戦での独立した距離の正解による
検証はまだ行っていない。

## 実装の検証

以下は初回校正時点の検証記録です。その後の帯・プレーヤー枠を含む5画像の比較では、
描画領域の自動判定に失敗すると距離比がずれる例を確認しました。
共通カメラの変更と領域判定の修正を区別するため、詳細と概算座標は
[測距の仕組み](../measurement.md#2026-09-26の比較で確認したこと)にまとめています。

- 型チェック、静的検査、本番ビルド、20件の自動テストが通過。
- Chromium / WebKit の操作・PNG出力テストが通過。
- 実画像の自動判定は3840px幅で `(0, 146, 3840, 1868)`、1920px幅で
  `(0, 73, 1920, 934)`、960px幅で `(0, 36, 960, 467)`。値は `(x, y, width, height)`。
- 対抗戦画像は `(0, 0, 1536, 709)` と判定され、誤った帯除去はなかった。
- 自動判定した領域での26点の円弧検証は誤差RMS約1.34px、最大約6.08px。
  アプリのPNG出力を `test-results/calibrated-range.png` に保存して目視確認した。
- Firefox は既存の検証用ブラウザが起動できず未検証（Bun / Node 両方で起動失敗）。
