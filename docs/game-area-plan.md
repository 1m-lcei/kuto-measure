# ゲーム領域の確認・設定・検出強化

## 確定仕様

- 読み込み時の自動検出結果は画像リソースに保持し、実際に使う領域と状態は編集ドキュメントに保持する。画像未選択時だけ領域は `null`。
- 領域の由来は `fallback`（画像全体で仮計算）、`auto`（帯を自動検出）、`manual`（手動適用）、`full`（画像全体を明示選択）。確認状態は別の `confirmed` フラグで持ち、新しい画像では自動検出の成否にかかわらず未確認から始める。
- 未確認時は画像サイズの下段に、同じ文字サイズの赤文字で「ゲーム領域が正しく判定されていない場合、設定の必要があります」と表示する。左の「OK」は現在の領域を変更せず確認済みにする。確認状態は履歴に含めるが、確認だけでは画像切替時の編集破棄確認を出さない。「ゲーム領域を設定」は基準パネルとゲーム領域設定を開いて最初の入力欄へフォーカスする。編集・PNG出力は継続可能。領域が画像全体と一致するときは「画像全体」とアスペクト比を表示する。
- 基準パネルの先頭に、標準では折りたたんだ「ゲーム領域」を置く。開くと上下左右の除外幅を元画像の整数pxで入力できる。全項目必須、0以上、残る幅・高さは1px以上。標準フォーム検証とモデルで検証する。
- 入力中は測定に反映せず、破線の矩形だけをプレビューする。適用は1操作。取消・Escape・パネルを閉じる操作・Undo/Redo・画像切替で未適用入力を破棄する。
- 「バーをドラッグして調整」は初期状態ではオフ。有効にすると上下左右のバーをマウス・タッチで動かせる。手動の「適用」が成功するとオフに戻す。数値入力と同じ未適用プレビューを使い、元画像の整数pxに丸め、画像内に幅・高さ1px以上を残す。バーは矢印キーで1px、Shift併用で10px調整できる。ドラッグの中断は未適用入力を破棄し、2本指に切り替えた場合は表示の移動・拡大縮小に移る。バーはゲーム領域の設定を開いている間だけ表示し、PNG・編集JSONには含めない。
- 「自動検出を適用」は読み込み時の結果を、「画面全体を適用」は4辺0を確認済みとして適用する。手動の「適用」も確認済みにし、数値適用が4辺0でも手動設定として扱う。
- 領域変更は既存のカメラ変更と同じ再投影処理を使う。ピンと自由な補助円中心の画像座標、基準円の中心と旧地面+X側の円周点を保持し、基準円の地面半径を再計算する。ゲーム内半径と参照関係は保持する。グループ中心・距離・スケールは再計算する。
- 変換不能・不正な円は変更全体を拒否する。領域外の既存データは削除せず、注釈は領域内にクリップする旨をフォームに表示する。
- 領域・状態・再投影したデータを同じ履歴に含める。同一領域で状態だけ変える場合は再投影しない。Undo/Redoで警告・入力値・境界・距離も復元する。
- 基準保存の形式は変えず、領域を含めない。保存時の検証と基準リセットには現在有効な領域を使う。基準リセットは領域設定を保持する。画像切替は再検出して状態を初期化する。
- 表示・当たり判定・投影変更・PNGに同じ適用済み領域を使う。PNGは画像全体を元解像度で保持し、編集用境界・入力中のプレビューを含めない。

## 検出方式

既存の青帯フォールバックだけに外れ値除去を追加する。左右各1/4の青い不透明画素を集め、RGB各成分の中央値から32を超えて離れる画素を除外して平均・分散を計算する。残った画素がサンプル範囲の70%以上であること、色の分散、行の連続性、対になる帯の厚さ、探索上限の既存条件は維持する。少数画素を除くために行を飛ばしたり、片側の帯から反対側を推測したりしない。

## 実装箇所

- `src/image.ts`: 青帯の外れ値除去。
- `src/model.ts`: 領域設定の型・検証・自動結果の状態化、領域変更を既存の投影変更に統合。
- `src/App.svelte`: 読み込み・履歴・保存基準・投影の接続、領域の確認警告、入力中プレビューの管理、境界バーの描画と操作。
- `src/Panels.svelte` / `src/style.css`: 領域の状態表示、数値フォーム、ドラッグ調整の切り替え、入力検証と適用・取消。
- `src/Annotations.svelte`: 適用済み領域の境界と、編集時だけの領域プレビューの描画。
- `src/annotations.ts` / `src/render.ts`: 注釈の共通計算とPNG出力用SVG。適用済み領域で注釈をクリップし、編集用境界・未適用プレビューは出力に含めない。
- `src/main.ts` / `index.html`: Svelteアプリの起動とマウント先。
- 既存テストとブラウザテスト、README・測定/幾何ドキュメントを更新する。

## 受け入れ条件

- 添付3枚をローカルのブラウザ処理で読み込み、上端約189px・下端約891pxを誤差3px以内で検出する。ユーザー画像はリポジトリに追加しない。
- 合成した青帯への左右・中央のカーソル、帯端の異物でも境界を検出する。黒帯、ホームインジケーター、薄いフッターの既存ケースを維持し、帯なし・単色・片側のみ・厚さ不一致・過大な異物を誤除外しない。
- 手動入力の空欄・負数・小数・非有限値・画像外・幅/高さ0を拒否し、ドキュメントを変更しない。
- 領域変更で画像上のアンカーが保たれ、距離が更新され、状態だけの変更では座標が変わらない。Undo/Redo、変換不能時の原子性、プリセットからの領域独立を確認する。
- 未確認警告、設定へのフォーカス移動、入力プレビューの未反映・取消、パネル開閉、画像切替、保存/リセット、PNGの元解像度とプレビュー非混入を3ブラウザで確認する。
- `bun run typecheck`、`bun run lint`、`bun run test`、`bun run build`、ビルド後の `bun run test:browser` を通す。デスクトップ/モバイル・明暗テーマを目視確認する。
